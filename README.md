# benjaminalt.github.io

Personal website, built with [Astro](https://astro.build/) and deployed to GitHub Pages
by [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) on every push to `master`.

Adapted from [al-folio](https://github.com/alshedivat/al-folio).

## Running the site locally

### Prerequisites

- Node.js 22.12 or newer (the version in [`.nvmrc`](.nvmrc); `nvm use` picks it up)
- [Git LFS](https://git-lfs.com/) — the paper PDFs under `public/assets/pdf/` are stored in LFS

### Setup

```bash
git clone --recurse-submodules git@github.com:benjaminalt/benjaminalt.github.io.git
cd benjaminalt.github.io
git lfs install && git lfs pull   # replaces the PDF pointer stubs with real files
npm ci
```

If the repository was cloned without `--recurse-submodules`, fetch the CV submodule with
`git submodule update --init --recursive`.

### Dev server

```bash
npm run dev
```

Serves the site at <http://localhost:4321> with hot reload. Content lives in
`src/content/posts/` and `src/content/news/`, publications in `src/data/publications.bib`.

A post's social preview card (`og:image`) is its frontmatter `image` if set, otherwise the
banner the post opens with (a leading `<Figure>` or markdown image), otherwise the portrait.
Cards are cropped to about 1.91:1, so set `image` to a 1200×628 version when the banner
would crop badly.

### Production build

```bash
npm run build     # runs scripts/check-lfs.mjs, then builds into dist/
npm run preview   # serves dist/ locally
```

`npm run build` fails if the PDFs are still LFS pointer stubs — run `git lfs pull` and retry.

Two files are generated by CI and are absent locally: `assets/pdf/cv.pdf` and
`assets/pdf/resume.pdf`, compiled with LaTeX from the `submodules/cv` submodule. The
verification scripts know this and skip those two URLs unless `CI=true`, so a local build
is expected to be missing the CV and resume links.

### Verification

The same checks CI runs. Run them against a fresh `dist/`, i.e. after `npm run build`:

```bash
node scripts/check-bib.mjs       # BibTeX parses, custom fields intact, no local paths leaked
node scripts/check-links.mjs     # every root-relative link in dist/ resolves
node scripts/check-assets.mjs    # e.g. pages rendering math also load katex.min.css
node scripts/url-parity.mjs      # no URL from the deployed baseline disappeared
```

`npm run parity` is a shortcut for the last one. `npm run format` applies Prettier to
`src/`.

`npm run check` runs `astro check` (TypeScript/Astro diagnostics) plus the bib check. It is
not part of the deploy pipeline and currently reports pre-existing type errors, so treat
its output as advisory.
